# v4.10 — UI/UX Revamp Implementation Plan ("Stadium Night: Broadcast Edition")

> **For agentic workers:** Execute with **superpowers:subagent-driven-development** — one fresh subagent per task. Implementation subagents run on **Sonnet** (design/integration tasks) or **Haiku** (mechanical tasks) as marked per task. Review checkpoints run on **Fable**. Steps use checkbox (`- [ ]`) syntax for resumable tracking — **this file is the single source of truth for progress.**

**Goal:** Revamp the entire UI/UX so the app looks and feels like it was built by a professional design/engineering team and is presentable at professional volleyball events — while keeping the existing color set (navy court blues, gold, team blue/orange) and changing everything else: typography, layout, components, iconography, motion.

**Architecture:** CSS-led redesign with surgical HTML restructuring and minimal JS edits confined to render helpers. A new design-token layer is introduced with **legacy aliases** so the app never breaks mid-migration; each screen is then rebuilt task-by-task and the aliases are retired at the end. Game logic (state machine, undo, persistence, rules) is **untouched**.

**Tech stack:** Vanilla HTML/CSS/JS (no build step), self-hosted Google Fonts (woff2), inline SVG icons, existing PWA service worker.

**Versioning (locked):** `app.js` → `APP_VERSION = 'v4.10'`; `index.html` footer → `v4.10`; `sw.js` → `VERSION = 'v4.1.0'` (cache key `vbref-v4.1.0`). New CHANGELOG entry `## v4.10`.

## 1. Design brief (locked decisions — do not relitigate)

The current theme is "Stadium Night" (dark navy arena, gold accents, glassmorphic panels). v4.10 evolves it into **"Broadcast Edition"** — the visual language of professional TV sports graphics: a score bug, team plates, a real court diagram, and confident condensed typography. Owner constraints from prior sessions still apply: **dark navy/gold stays** (wood/cream retheme rejected), **no confetti** (rejected).

| Decision | Choice |
|---|---|
| Palette | Unchanged hues: navy `#071545/#0d2055/#152b7a/#1a348f`, gold `#f5c842/#d4a017`, white ink, team defaults blue `#2979ff` / orange `#ff8f00`. Reorganized into tokens, not changed. |
| Display font | **Big Shoulders Display** (600, 800) — athletic condensed, replaces Bebas Neue. Used for scores, headings, buttons, team names. |
| Body font | **Saira Semi Condensed** (400, 500, 600, 700) — replaces Barlow Semi Condensed. |
| Font delivery | **Self-hosted woff2** in `fonts/` (added to SW `APP_SHELL`). Google Fonts `<link>`s removed — fonts now work offline and don't FOUT on bad venue Wi-Fi. |
| Iconography | All PNG UI icons (`timer.png`, `undo.png`, `swap.png`, serve-ball `volleyball.png` usage in markup) replaced with **inline SVG**, `stroke="currentColor"`, crisp at any DPI. `volleyball.png` stays only as favicon/manifest icon. |
| App shell | New slim fixed **app bar** (brand wordmark left, feedback/settings actions right) replaces the floating `<h1>` + floating `.top-actions`. |
| Scoreboard | Broadcast layout: hero scores in display font (`clamp` fluid sizing), team name plates with team-color bars, **team-color-tinted +1 buttons** (replacing the green gradient), center column = serve indicator + undo/swap + set chips. `VS` text retired (CSS-hidden). |
| Rotation screens | Rotation grids drawn as a **real court diagram**: net strip on the front-row edge, dashed attack line, zone badges. |
| Modals | Unified shell: stronger backdrop blur, centered card on desktop, **bottom sheet on ≤600px** with slide-up animation. |
| Motion | Purposeful and few: screen entrance fade-up, score pop (existing `pulseScore` hook restyled), modal slide/fade, serve pulse. Full `prefers-reduced-motion` support (block already exists — must keep working). |
| Match type control | Radio inputs preserved (JS contract) but rendered as a **segmented control**. |

**Aesthetic acceptance bar for every task:** no element may look like default browser chrome; spacing comes from the token scale; text styles come from the type scale; any deviation is a defect.
